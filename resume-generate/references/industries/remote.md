## 行业概述

远程岗位最看重**自驱力、异步沟通能力与文档化习惯**。简历需体现候选人在无监督环境下独立交付的能力和出色的书面沟通。

## 关键词库

在经历描述和个人总结中自然融入以下关键词：

- 远程协作（Remote Collaboration）
- 异步沟通（Async Communication）
- 自驱力（Self-Driven）
- 文档能力（Documentation）
- 跨时区（Cross-Timezone）
- 独立交付（Independent Delivery）
- RFC / Design Doc
- Written Communication
- 分布式团队（Distributed Team）
- 结果导向（Outcome-Oriented）

## Bullet 改写策略

- **角度**: 聚焦沟通产出物、独立交付记录、异步协作流程
- **量化**: 优先使用文档数量、跨时区协作覆盖、独立交付周期、review 周转时间
- **文档**: 体现 RFC、Design Doc、ADR 等书面决策习惯
- **自治**: 强调无需频繁 sync 即可高质量交付的能力

## Summary 改写指导

远程岗位投递时，summary 段需突出：
- "具备 N 年远程/分布式团队协作经验"
- 强调异步沟通优先、文档驱动开发
- 提及跨时区协作经历（覆盖时区范围）
- 定位为 "reliable self-starter with strong written communication"

## 改写示例

| 原始 | 改写后 |
|------|--------|
| 和团队成员合作完成需求 | 在横跨 3 个时区的分布式团队中，通过 RFC + 异步 Review 流程独立推进技术方案，平均 PR 周转时间 < 4h |
| 写了技术文档 | 建立团队文档体系（Design Doc / ADR / Runbook），累计产出 50+ 篇技术文档，显著降低异步协作中的信息差 |

## 加分项

- 开源社区贡献经历（天然的异步协作证明）
- 个人技术博客或公开写作（体现书面表达能力）
- 跨文化沟通经验（英文工作环境）
- 远程工具栈熟练度（Notion, Linear, Loom, Slack）
