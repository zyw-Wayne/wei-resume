## 行业概述

AI/ML 公司重视**模型效果、数据规模和工程化能力**。简历需体现候选人在模型训练、推理优化和数据处理管线方面的量化成果。

## 关键词库

在项目描述和 AI 能力区中自然融入以下关键词：

- 模型（Model）
- 推理（Inference）
- 训练（Training）
- 数据集（Dataset）
- Embedding
- Fine-tune / 微调
- RAG（Retrieval-Augmented Generation）
- Agent / 智能体
- Prompt Engineering
- 特征工程（Feature Engineering）
- MLOps / 模型部署
- 向量数据库（Vector DB）

## Bullet 改写策略

- **角度**: 聚焦 ML Pipeline、模型性能指标、数据处理规模
- **量化**: 优先使用模型指标（AUC, F1, BLEU, latency）、数据规模（TB 级）、推理 QPS
- **工程化**: 体现从数据采集到模型上线的全链路能力
- **前沿性**: 适度提及 LLM、Agent、RAG 等当前热点技术的实践经验

## AI 能力区强化

本行业投递时，ai-capability section 权重最高，建议：
- 详细列出 AI 工具使用经验（Cursor, Copilot, Claude 等）
- 展示 AI-assisted 开发的效率提升数据
- 如有 Agent 编排、Prompt 工程经验，独立列出
