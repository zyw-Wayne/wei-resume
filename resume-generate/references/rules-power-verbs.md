# Power Verb Rules for Resume Bullets

Loaded during every Phase 2 section generation to ensure strong, active wording.

## Chinese Bullets: 动宾结构开头

Every Chinese bullet point must start with a strong verb in 动宾 (verb-object) structure.

**技术类动词:**
设计、架构、实现、开发、搭建、优化、重构、迁移、集成、构建、部署、封装、抽象

**管理类动词:**
主导、推动、协调、带领、负责、规划、制定、组织、统筹、牵头

**成果类动词:**
提升、降低、缩短、实现、达成、保障、支撑、赋能、交付、落地

## English Bullets: Action Verb (Past/Present Tense)

Use past tense for previous roles, present tense for current role only.

**Technical:**
Architected, Designed, Implemented, Developed, Built, Optimized, Refactored, Migrated, Integrated, Engineered, Deployed, Automated

**Leadership:**
Led, Drove, Coordinated, Mentored, Spearheaded, Established, Founded, Directed, Championed

**Results:**
Improved, Reduced, Accelerated, Achieved, Delivered, Enabled, Increased, Streamlined, Eliminated, Scaled

## Weak Verbs to AVOID

These verbs are too vague and must be replaced with stronger alternatives:

- ❌ 参与了 → ✅ 负责 / 主导 / 实现 (be specific about contribution)
- ❌ 负责了 (without specifics) → ✅ 负责 + concrete deliverable
- ❌ Helped → ✅ Contributed to / Implemented / Delivered
- ❌ Assisted → ✅ Supported / Enabled / Coordinated
- ❌ Was responsible for → ✅ Led / Managed / Owned
- ❌ Worked on → ✅ Developed / Built / Designed
- ❌ Did → ✅ Executed / Delivered / Completed

## Bullet Structure

**Formula:** Verb + What + How + Result (quantified when possible)

## Examples

**Good:**
- ✅ "设计并实现了基于 gRPC 的订单服务，支撑日均 50 万笔交易"
- ✅ "Architected event-driven order processing pipeline handling 500K daily transactions"
- ✅ "主导前端性能优化，首屏加载时间从 4.2s 降至 1.1s"
- ✅ "Led frontend performance optimization, reducing initial load time from 4.2s to 1.1s"

**Bad:**
- ❌ "参与了订单系统的开发工作"
- ❌ "Helped with the order system"
- ❌ "负责了一些前端的优化"
- ❌ "Was responsible for some frontend improvements"
